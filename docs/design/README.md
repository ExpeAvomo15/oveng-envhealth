# Mockups oficiales

Aquí van las **2 infografías de diseño oficiales** del producto (las sube el
autor del proyecto).

Son la referencia estética vinculante: toda pantalla nueva replica lo que se ve
aquí antes de inventar variantes. Si algo no aparece en los mockups, se deriva
de la paleta y los tokens fijados en AGENTS.md:

| Token           | Valor     |
| --------------- | --------- |
| Verde           | `#2E7D32` |
| Verde claro     | `#A5D6A7` |
| Azul            | `#02B8D1` |
| Amarillo        | `#FFC107` |
| Gris            | `#616161` |
| Superficie      | `#F4F6F9` |

Cards con radio ~16px. El verde se usa **solo como acento**, no como fondo
dominante.
